# Support

Descriptor is an early open-source project maintained on a best-effort basis.

- Setup and usage question: start with `docs/GETTING_STARTED.md` and GitHub Discussions if enabled.
- Reproducible product bug: open a bug report with redacted logs and synthetic/authorized media details.
- Feature proposal: open a feature request and describe the creator problem before the implementation idea.
- Security vulnerability: use a private GitHub security advisory; never post it publicly.

Do not send source media or full transcripts to maintainers unless a private, explicit, and authorized debugging arrangement has been agreed. There is no guaranteed support response time, compatibility promise for unreleased features, or recovery service for local project data.
